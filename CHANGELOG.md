# Changelog

Versions follow [Semantic Versioning](https://semver.org/): `MAJOR.MINOR.PATCH`.
Each release is a git tag (`v1.0.0`, `v1.1.0`, …) on `main`.

- **MAJOR** — a redesign or a change of structure
- **MINOR** — a new section, project or feature
- **PATCH** — fixes and copy edits

## v1.0.0 — 2026-11-13

First official release: full redesign of the site and the brand identity v3.0 "Deep Blue".

- Professional title and all content aligned with the CV: UI/UX Designer & Front-End Developer
- New language and theme controls (sliding segment, morphing sun/moon), transitions kept
- Header call to action "Work with me"
- "What I Use" rebuilt: tools grouped by discipline and tied to the certificates behind them
- "What I've Built": four live projects in a 3D scroll stage, with detail dialogs and live links
  (Programming Worlds, Malak Coffee, Yaser Samer, Ramz Technical Conference — dashboard)
- "How I Got Here" rewritten with evidence for each step
- "Let's Build Something": every contact channel from the CV; contact form removed
- Minimal footer
- Code reorganised: content / sections / components / lib; dead code and old files removed
- Responsive from 320 px phones to wide desktops, in both languages and both themes
